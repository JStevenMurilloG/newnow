# 11 · Glosario

## Términos del dominio

| Término | Definición |
| --- | --- |
| Lugar | Ámbito geográfico activo: mundo, región, país o ciudad |
| Región | Uno de los siete grupos de países definidos por la app |
| Titular | Noticia principal devuelta por el endpoint `top-headlines` |
| Feed | Lista de noticias del lugar y la categoría activos |
| Destacada | Primer artículo del feed, mostrado con mayor tamaño |
| Tendencias | Artículos más populares del lugar en los últimos siete días |
| Última hora | Etiqueta del titular principal si tiene menos de tres horas |
| Categoría | Tema de las noticias: Portada, Economía, Tecnología, Ciencia, Salud, Deportes, Cultura |
| Guardado / marcador | Noticia almacenada por el usuario para leer después |
| Extracto | Fragmento del artículo que entrega NewsAPI |
| Fuente | Medio de comunicación que publicó el artículo |
| Punto de interés (hotspot) | Lugar del globo mencionado en los titulares cargados |
| Orbe | Miniatura del globo que aparece en la barra superior al desplazarse |
| Hero | Sección superior de la portada con el globo y la información del lugar |
| Hoja del lugar | Panel inferior que resume un lugar en móvil |
| Cuota | Número máximo de peticiones diarias que permite NewsAPI |

## Términos técnicos

| Término | Definición |
| --- | --- |
| PWA | Aplicación web progresiva: web instalable que puede funcionar sin conexión |
| SPA | Aplicación de una sola página que cambia de vista sin recargar |
| Service worker | Programa del navegador que intercepta peticiones y gestiona la caché |
| Workbox | Biblioteca que genera el service worker |
| Manifiesto | Archivo que describe la app instalable (nombre, iconos, colores) |
| Proxy | Servicio intermedio entre el navegador y NewsAPI que añade la API key |
| Función serverless | Código de servidor que se ejecuta bajo demanda sin administrar servidores |
| Middleware | Función que atiende peticiones dentro del servidor de desarrollo |
| API key | Clave secreta que identifica a la app ante NewsAPI |
| Endpoint | Dirección concreta de una API |
| Lista blanca | Conjunto cerrado de valores permitidos |
| Caché | Copia temporal de datos para no volver a pedirlos |
| staleTime | Tiempo durante el cual un dato en caché se considera vigente |
| NetworkFirst / CacheFirst | Estrategias de caché: intentar primero la red o primero la copia |
| WebGL | Tecnología del navegador para gráficos 3D |
| Canvas | Elemento donde se dibuja el globo |
| TopoJSON / GeoJSON | Formatos de datos geográficos |
| Centroide | Punto central de un país, usado para enfocar la cámara |
| ISO 3166-1 alfa-2 | Código de país de dos letras (co, mx, es) |
| Slug | Identificador legible en la URL (bogota, nueva-york) |
| Token de diseño | Variable que guarda un valor visual reutilizable |
| Toast | Aviso breve que desaparece solo |
| Esqueleto | Marcador de posición que se muestra mientras cargan los datos |
| View Transition | Animación del navegador entre dos vistas |
| ARIA | Atributos que describen la interfaz a tecnologías de asistencia |
| WCAG | Pautas de accesibilidad para el contenido web |
| MoSCoW | Priorización: Must, Should, Could, Won't |
| Historia de usuario | Requisito descrito desde la necesidad de quien usa el producto |
| Épica | Conjunto de historias con un objetivo común |
| DoR / DoD | Definition of Ready / Definition of Done |
| ADR | Registro de una decisión de arquitectura |
| SRS | Especificación de requisitos de software |
| CI | Integración continua: verificación automática de cada cambio |
